# ブラウザ画面設計

## 主要画面

| 画面 | 表示と操作 |
| --- | --- |
| 端末一覧 | 名前、OS、接続先、最終確認時刻、端末状態、現在のジョブを表示。端末登録と接続テスト、手動操作、複数選択による実行を行う。 |
| リモート操作 | 選択した1台の画面、映像状態、操作権、記録状態を表示。クリック、長押し、ドラッグで実機を操作する。 |
| シナリオ編集 | ステップ一覧と選択ステップの設定を表示。追加、並べ替え、削除、条件分岐先選択、保存、試行、インポート・エクスポートを行う。 |
| 画像条件編集 | 静止したスクリーンショットから照合画像と探索範囲を選ぶ。別画像で照合し、検出矩形、一致スコア、最終判定を確認する。 |
| 実行モニター・履歴 | 端末ごとのステップ、分岐、経過時間、状態、失敗理由を表示。端末単位と実行全体の停止、結果と診断画像の確認を行う。 |

## リモート操作

描画は縦横比を維持し、画像が占める矩形を基準にポインタ位置を正規化する。余白から始まる操作は無効にする。ブラウザの表示倍率は比率計算で吸収する。

- 左クリックでタップ。ドラッグをせず一定時間押し続けると長押し。移動量が閾値を越えた場合は、開始点、終了点、継続時間を使ってスワイプする。
- ジェスチャーはポインタを離した時に確定する。キャンセルや画像外での終了、操作中の画面向き・表示領域変更では送信しない。
- クリックスルーを防ぐため、直前の操作結果を待つ間は新しい操作を無効にする。端末切替時は前端末の操作権と映像購読を解放する。
- フレームが停止した場合は最後の画面を表示してもよい。更新停止を明示し、操作は無効にする。
- 「検出位置をタップ」の試行では、押下前に検出矩形とタップ予定点を表示できる。

## 記録から複数実行まで

1. 端末を選び、操作権を取得する。
2. 「記録開始」を押して実機を操作する。操作の完了が確認できたものから記録一覧に追加する。
3. 記録を止め、待機時間や分岐を編集する。画像を登録したい場合は現在画面を静止して範囲を切り出す。
4. 保存して1台で試行する。失敗した場合は該当ステップの設定や判定ログを開く。
5. 端末一覧から配信先を選択し、シナリオ名・保存版・対象端末を確認して実行する。

画面を再読み込みしても、保存済みのシナリオと、ホストに記録済みの下書き・実行結果を取り直せる。接続断で操作の結果が不明な場合は再送せず、現在画面の確認を促す。
