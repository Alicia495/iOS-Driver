# 製品仕様

## 目的と対象

iPhoneの画面をPC上で見ながら手動操作し、その操作をシナリオとして保存する。画面内のボタン・アイコン・ダイアログを識別し、同じ手順を複数端末に配信しても各端末の表示に応じて次の操作を決められるようにする。

対象は所有または管理する実機iPhoneと、同一拠点の管理用LAN。ホストはWindows／macOS。クライアントはPCのブラウザ。初期開発はMac上でホスト・クライアント・Appiumを動かし、ペアリングした実機で試験する。iOS 18以降を共通設計の対象候補とし、対応を確認した組み合わせは[検証計画](../quality/acceptance.md)に従って記録する。

## 初版の機能

| ID | 機能 | 要求 |
| --- | --- | --- |
| R01 | 端末管理 | 名前、UDID、OS、接続先を登録し、利用可能・実行中・接続異常などを確認できる。 |
| R02 | リモート操作 | 選択した1台のライブ画面上でタップ、長押し、スワイプを実機に即時送信する。Windowsホストでも同じ操作ができる。 |
| R03 | 記録・編集 | ブラウザから送信し完了したジェスチャーと操作間隔を記録し、手順の移動、削除、待機の変更ができる。 |
| R04 | 画像条件 | 画面の切り出しを登録し、検出候補の位置とスコアを試験できる。画像を待つ、条件で分岐する、検出位置をタップする操作を作れる。 |
| R05 | 試行 | 1台を選んで実行し、進捗を確認しながら停止できる。画像条件は保存画像でも試せる。 |
| R06 | 複数台実行 | 同じシナリオ版を選択端末に配信し、端末ごとに独立して進行、分岐、停止する。ブラウザを閉じても実行は続く。 |
| R07 | 履歴 | 端末別の実行結果、現在／最終ステップ、分岐、接続エラー、失敗時の取得可能な画面を確認できる。 |
| R08 | 移行 | シナリオと画像素材をまとめて書き出し、Windows／macOS間で取り込んで利用できる。 |

## 初版の範囲

- 手動操作を記録する入口はブラウザのみ。ジェスチャーは確定後に送信する。端末上で指を動かし続ける操作の転送、マルチタッチ、iPhone本体で触った操作の取得は対象外。
- 画像判定は固定図柄に対応。OCR、物体検出、画面全体を理解するモデル、UI要素のセレクター編集は後続候補。
- 同時実行の単位は端末ごと。全台に同じ命令を同一時刻に到達させる精度や、全台のライブ映像常時表示は初版の要件外。
- 数十台の管理と並列実行を設計目標とする。ホスト当たりの同時稼働台数と帯域は実測で決定する。
- 利用者は管理担当者を想定。インターネット越しの公開や複数組織向け管理は初版の範囲外。

## 代表シナリオ

代表端末を選び、ライブ画面で「開始」をタップして記録する。次に、表示領域から「次へ」と「再試行」の画像を登録する。記録したタップの後に最大8秒の判定を入れ、「次へ」なら検出位置をタップ、「再試行」なら別の手順へ進み、どちらも表示されなければ停止する。同じシナリオを複数台で動かし、実行結果から各端末が選んだ分岐を確認する。
