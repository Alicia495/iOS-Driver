## 設計上の区分

- **合意済み**。ホストはWindows／macOS両対応。初期開発と実機確認はMac。どちらのホストでもブラウザで画面を見ながら記録・編集・実行する。iPhone側はAppium／WDAを使用する。
- **初版の設計判断**。固定画像の照合、ジェスチャー単位の遠隔操作、端末ごとの独立実行を採用する。各資料の既定値は実装開始時の値とする。
- **実機検証待ち**。Windowsでの直接無線接続と復帰、OS・端末モデルの対応表、数十台の同時実行容量と映像遅延。測定後に運用値を更新する。
